# Prabhjot Singh portfolio

## Direction
Build a single-page, editorial portfolio rooted in the supplied presentation: off-white paper, deep navy typography, crisp white space, and restrained coral accents. Use one confident sans-serif family, squared edges, and subtle motion rather than decorative effects.

## What will be built
- A minimal sticky header with anchor navigation and a compact mobile menu.
- A first-screen introduction featuring Prabhjot Singh, his VET positioning, exact supporting statement, services, portrait crop, and two clear actions.
- A credentials and client-experience band using the four supplied client logos from the portfolio.
- One continuous Albury College transformation story: case-study introduction, prominent before and after evidence, exact observations and outcome copy, and an interactive visual comparison.
- Two editorial work galleries for painting and carpentry examples, preserving the supplied captions and strategic framing.
- A visual content-mix system using the exact percentages and category copy.
- A restrained services section and final contact prompt using only claims supported by the supplied material.
- A lightbox for portfolio imagery, gentle hover zoom, scroll reveals, smooth anchor navigation, and reduced-motion support.

## Assets and content
- Extract the portrait, logos, feeds, and individual social posts from the uploaded screenshots for use as real portfolio evidence.
- Preserve visible wording and brand examples; do not add metrics, testimonials, clients, achievements, or services.
- Use clear alt text and avoid reproducing screenshot page chrome or turning the original slides directly into page sections.

## Technical details
- Implement the page at `/` with responsive React/Tailwind composition and semantic design tokens in the global stylesheet.
- Add app-specific page metadata and load the chosen web font in the document head.
- Use accessible dialog behavior for the image viewer and keyboard-friendly navigation.
- Verify the finished page at desktop and mobile sizes, including menu, links, comparison control, and lightbox.
